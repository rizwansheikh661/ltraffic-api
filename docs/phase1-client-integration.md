# Phase 1 client integration

This release implements the backend work for Bulletins, Timesheets, Incidents,
User Management and My Account. Notifications and Contact Directory are out of
scope for this release.

## Required migration

Run `npm run schema:apply` against the target database before deploying this
API version. It creates:

- `lt_content_pages` for About Us, Privacy Policy and Terms & Conditions.
- `lt_timesheet_options` for admin-managed Activities and Contracts.

## Employee app

1. After `POST /auth/login`, inspect `bulletinAcknowledgementRequired` and
   `pendingBulletinCount`.
2. When acknowledgement is required, open the Bulletin screen immediately and
   do not show the main dashboard.
3. Call `GET /employee/bulletins/pending`, render every item, then call
   `POST /employee/bulletins/:id/acknowledge` for each item.
4. Until all items are acknowledged, every non-bulletin `/employee/*` endpoint
   returns `403 BULLETIN_ACKNOWLEDGEMENT_REQUIRED`.
5. Build a timesheet from one to seven distinct user-selected dates. Load the
   active dropdown values from `GET /employee/timesheets/options`.
6. Read About Us, Privacy Policy and Terms & Conditions from
   `GET /account/pages/:slug`.

## Admin app

- User levels: `GET /admin/users/levels`.
- Create/update users with the friendly `level_id` (1–9). The legacy
  PHP-serialised `user_level` request field remains supported for compatibility.
- Set `restricted: 1` to block a user immediately; their refresh sessions are
  revoked and every authenticated request checks the restriction flag.
- Reset a user's password by sending `password` in `PUT /admin/users/:id`.
- Manage Activity/Contract values with `GET|POST /admin/timesheets/options` and
  `PUT|DELETE /admin/timesheets/options/:optionId`. Delete deactivates an
  option rather than changing historic timesheets.
- Review every incident via `GET /admin/incidents`. To close an incident, send
  `POST /admin/incidents/:id/status` with `status: "Closed"` and non-empty
  investigation `notes`.
- Edit My Account content with `PUT /account/pages/:slug` as Admin/Admin1.

## Frontend-only item

The Vehicle Checks count/statistic is not generated by `ltraffic-api` (there
is no dashboard statistic endpoint). Remove that card/count in the relevant
admin or employee dashboard UI.
